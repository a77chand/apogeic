Demo cheat sheet: designs that earn 3 stars

For the team only (not part of the game). Found by trying every combination of the parts each mission offers, with the game's own rules. Generated 15 Nov 2026 from branch branchzies.
  • Best = the cheapest design that earns all 3 stars (goal reached, every check passed, 10% budget left). "Other winners" are the next cheapest; the last column counts every 3-star design.
  • Numbers assume you press Test it by about day 40 (each extra day adds team pay) and fix every problem the test lab finds (an unfixed flaw can make the launch fail). Random events in orbit can still cost data or money, so choose the safe option on event cards.
  • Parts are scaled to the CubeSat size, so a 1U part is lighter and weaker than the same part on a 6U. Satellite missions use the 3U-sized numbers.
